# insta-autodm

인스타그램 댓글에 자동으로 DM을 보내는 서버입니다. 인포크·ManyChat 같은 유료 서비스의 "댓글 자동 DM" 기능을 내 계정 전용으로 직접 운영합니다.

- **무료**: Cloudflare Workers 무료 플랜과 D1 데이터베이스로 돌아갑니다. 컴퓨터를 켜 둘 필요가 없습니다.
- **공식 API만 사용**: Instagram API with Instagram Login을 씁니다. 비밀번호 로그인이나 브라우저 자동화를 쓰지 않습니다.
- **앱 심사 불필요**: 내가 관리하는 계정에만 쓰면 Meta 앱 심사(App Review)와 비즈니스 인증이 필요 없습니다. 앱을 Publish만 하면 됩니다.

## 동작 흐름

```
사용자가 키워드 댓글 작성
  → 댓글에 비공개 답장(첫 DM) + "팔로우 확인 🙌" 버튼
  → 사용자가 버튼을 누름
  → 서버가 팔로우 여부 확인 (is_user_follow_business)
      ├ 팔로워   → 링크 DM (링크 버튼 최대 3개)
      └ 비팔로워 → 팔로우 안내 + 버튼 다시 보내기
  → (선택) 댓글에 공개 답글 달기
```

## 기능

- 게시물별 자동화, 또는 "다음에 올릴 게시물" 자동화 (올리면 자동으로 연결)
- 발송 시점: 즉시 발송 / 예약 발송(정한 시간에 한 번에) / 일괄 발송(최근 7일 댓글에 한 번에)
- 키워드 여러 개 (비우면 모든 댓글에 반응)
- 팔로워 구분 켜기/끄기 (끄면 바로 링크 DM)
- 링크 DM에 웹 링크 버튼 0~3개
- 댓글 공개 답글 (여러 문구 중 무작위 선택)
- 계정 여러 개를 한 서버에서 운영
- 관리 화면: 비밀번호로 보호, 보낸 DM·팔로우 확인·링크 전송 통계
- 같은 이벤트가 다시 와도 DM은 한 번만 (D1에 30일 보관 후 자동 삭제)
- webhook 서명(`X-Hub-Signature-256`) 검증

## 설치

**[docs/SETUP.md](docs/SETUP.md)** 를 처음부터 순서대로 따라 하면 됩니다. AI 코딩 에이전트(Claude Code, Codex 등)에게 이 저장소를 열고 "docs/SETUP.md대로 설치해 줘"라고 요청해도 됩니다. 사람이 직접 눌러야 하는 단계는 문서에 `👤 사람`으로 표시되어 있습니다.

필요한 것:

| 항목 | 비고 |
| --- | --- |
| 인스타그램 프로페셔널 계정 | 비즈니스 또는 크리에이터 계정. 개인 계정은 API를 쓸 수 없습니다 |
| Meta 개발자 계정 | developers.facebook.com, 페이스북 계정으로 가입 |
| Cloudflare 계정 | 무료 플랜 |
| 개인정보처리방침 웹페이지 | 공개 URL 1개. [템플릿](docs/privacy-policy-template.md) |
| Node.js 18 이상 | 배포 도구(wrangler) 실행용 |
| 테스트용 인스타그램 계정 | 내 계정에 내가 단 댓글에는 DM이 가지 않습니다 |

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `src/index.js` | Worker 진입점. `/webhook`(Meta) + `/`(관리 화면, Basic 인증) |
| `src/logic.js` | 댓글 → DM → 팔로우 확인 → 링크 DM 흐름 |
| `src/admin.html` | 관리 화면 |
| `schema.sql` | D1 표 (자동화 설정, 통계, 중복 방지 기록) |
| `test.mjs` | 오프라인 검사 (`npm test`) |
| `scripts/push-secrets.sh` | `.env` 값을 Cloudflare secret으로 등록 (값을 출력하지 않음) |

## 한도와 주의 사항

- 댓글 비공개 답장은 **계정당 시간당 750건**, 댓글 작성 후 **7일 이내**, **댓글 1개당 1번**만 보낼 수 있습니다 ([Meta rate limits](https://developers.facebook.com/docs/messenger-platform/overview/rate-limiting)).
- 이 서버는 계정당 **1분 12건, 1시간 720건**까지만 보냅니다. Meta 한도(1시간 750건)보다 조금 적게 잡은 값입니다. 예약 발송·일괄 발송은 1분마다 12건씩 나눠 보냅니다. 댓글 120개면 약 10분이 걸립니다.
- 한도에 걸린 DM은 버리지 않습니다. 다시 보낼 목록(`retry` 표)에 넣고 1분 뒤에 다시 보냅니다.
- Cloudflare 무료 플랜은 한 번 실행할 때 외부 호출을 50번까지만 허용합니다. 그래서 예약·일괄 발송은 1분에 계정 1개씩 처리합니다. 두 계정의 일괄 발송이 겹치면 번갈아 처리합니다.
- 예약·일괄 발송은 게시물 하나당 최근 댓글 300개까지만 읽습니다.
- 토큰은 **60일**마다 만료됩니다. [SETUP.md의 토큰 연장](docs/SETUP.md#토큰-연장-60일마다)을 참고하세요.
- 같은 계정에서 다른 자동 DM 서비스가 켜져 있으면 DM이 두 번 갑니다.
- 받는 사람이 DM을 스팸으로 신고하면 계정에 불리합니다. 댓글을 단 사람에게만 보내는 구조라 위험은 낮지만, 키워드와 문구는 상식적으로 운영하세요.
